# Sahel Harvest Link

# PROJECT: SUGULINK — PREMIUM AGRICULTURAL MARKETPLACE MOBILE APP

Act as a world-class UI/UX designer, senior product designer and frontend engineer specializing in premium mobile applications, agricultural marketplaces, African fintech and logistics platforms.

Your mission is to design and build a COMPLETE, exceptionally modern, professional and interactive mobile application prototype called **SuguLink**.

IMPORTANT: This is a UI/UX reference project. The final application will eventually be developed natively using C# and .NET MAUI in Visual Studio.

You are free to use your preferred frontend technologies. However, focus exclusively on creating an outstanding visual experience and functional frontend prototype.

Do not waste credits implementing a backend, database, Supabase, authentication server or external APIs.

Use realistic mock data and local state to simulate interactions.

---

# 1. PROJECT VISION

SuguLink is an innovative agricultural marketplace connecting four major actors in the agricultural supply chain:

1. AGRICULTURAL PRODUCERS
2. MERCHANTS
3. TRANSPORTERS
4. BUYERS

The platform aims to simplify agricultural commerce by connecting producers directly with buyers, facilitating wholesale transactions, organizing transportation and improving access to agricultural products.

Initial target market: Mali, with the possibility of expanding throughout West Africa.

The application must be designed with African market realities in mind.

Use FCFA as the currency.

Use realistic African names, locations and agricultural products.
